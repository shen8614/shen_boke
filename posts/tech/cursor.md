    13|# Cursor：为 AI 而生的代码编辑器
    14|
    15|> 官网：[https://cursor.com](https://cursor.com)
    16|
    17|## 简介
    18|
    19|Cursor 是一款基于 VS Code fork 的 AI 原生代码编辑器，由 Anysphere 团队开发。它将 AI 能力深度嵌入编辑器的每一个角落，从代码补全到项目级重构，从单文件编辑到多 Agent 协作，目标是让开发者把精力花在真正需要思考的地方。
    20|
    21|与传统的"编辑器 + AI 插件"模式不同，Cursor 从底层就为 AI 协作设计。它的 Tab 补全能预测你接下来几行要写什么，Cmd+K 能让 AI 直接改写选中代码，Agent 模式更是能自主分析项目结构、跨文件重构。
    22|

    77|## 核心功能
    78|
    79|### Tab 补全
    80|
    81|Cursor 的 Tab 补全是目前体验最好的。它不只是补全当前行，而是能预测你接下来几行要写什么，按下 Tab 就能接受整段建议。
    82|
    83|写 React 组件时经常出现这样的场景：你写了 `const [data, setData] =`，它直接补全 `useState(null)` 并且光标跳到下一行准备写 `useEffect`。这种"读心术"级别的补全在写重复性代码时效率极高。
    84|
    85|Tab 补全的特点：
    86|- **多行预测**：不只是当前行，能预测接下来 3-5 行
    87|- **上下文感知**：理解整个文件的上下文，补全更准确
    88|- **快速接受**：Tab 接受，Esc 拒绝，Ctrl+→ 逐词接受
    89|
    90|### Cmd+K 编辑
    91|
    92|Cmd+K 是 Cursor 的核心交互——选中代码，描述你想做什么，AI 直接改。
    93|
    94|```text
    95|# 选中代码后 Cmd+K
    96|"把这段代码改成 async/await 风格"
    97|"为这个函数加上错误处理"
    98|"优化这段代码的性能"
    99|
   100|# 在空白处 Cmd+K
   101|"写一个 React Hook 用于表单验证"
   102|"生成一个 REST API 的 CRUD 接口"
   103|```
   104|
   105|Cmd+K 支持多次迭代：第一次改完后可以继续 Cmd+K 微调，直到满意为止。
   106|
   107|### Agent 模式
   108|
   109|2025 年底 Cursor 引入了 Agent 模式，将能力从"改选中的代码"扩展到了"改整个项目"：
   110|
   111|- **自动分析项目结构**：理解目录组织、依赖关系
   112|- **跨文件搜索和修改**：找到所有相关文件并逐一修改
   113|- **执行终端命令**：运行测试、安装依赖、启动服务
   114|- **交互确认**：遇到不确定的地方会停下来问你
   115|
   116|```text
   117|# Agent 模式下的典型对话
   118|"把所有 class 组件改成 hooks"
   119|"给所有 API 接口加上参数校验"
   120|"把这个模块从 JavaScript 迁移到 TypeScript"
   121|```
   122|
   123|### .cursorrules 项目记忆
   124|
   125|Cursor 用 `.cursorrules` 文件来控制 AI 的行为。在项目根目录创建这个文件：
   126|
   127|```text
   128|# .cursorrules 示例
   129|这是一个 Spring Boot + Vue 3 全栈项目。
   130|
   131|## 后端规范
   132|- Java 17，Spring Boot 3.x
   133|- 代码风格遵循 Google Java Style Guide
   134|- 所有 API 必须有单元测试
   135|- 禁止使用 Lombok
   136|
   137|## 前端规范
   138|- TypeScript，Vue 3 Composition API
   139|- 使用 Pinia 管理状态
   140|- 组件命名使用 PascalCase
   141|- 禁止使用 any 类型
   142|```
   143|
   144|这个文件会被注入到每次 AI 对话的 system prompt 中，效果比每次手动提醒好得多。
   145|
   146|### 多模型支持
   147|
   148|Cursor 支持切换底层模型：
   149|- **Claude 3.5 Sonnet**：默认模型，综合能力最强
   150|- **GPT-4o**：推理能力突出
   151|- **Claude 3.5 Haiku**：速度快，适合简单任务
   152|
   153|在 Settings → Models 中可以切换。

   155|## 使用场景
   156|
   157|### 日常编码
   158|
   159|```bash
   160|# 快速生成一个 REST API
   161|Cmd+K: "给 UserController 加一个分页查询接口，支持按姓名模糊搜索"
   162|
   163|# 重构代码
   164|选中一段代码 → Cmd+K: "把这段代码提取成一个独立的 service 方法"
   165|
   166|# 写测试
   167|选中一个函数 → Cmd+K: "为这个函数写单元测试，覆盖边界情况"
   168|```
   169|
   170|### 大规模重构
   171|
   172|Agent 模式下可以说"把所有 class 组件改成 hooks"，Agent 会分析项目结构，逐个文件修改。
   173|
   174|### 代码审查
   175|
   176|选中一段代码，Cmd+K 问"这段代码有什么潜在问题？"，AI 会给出分析和改进建议。

   178|## 优势
   179|
   180|1. **Tab 补全质量最高**：预测准确率高，能补全多行代码
   181|2. **Agent 模式成熟**：跨文件重构能力强，能自主分析项目
   182|3. **VS Code 生态兼容**：直接继承 VS Code 的插件生态
   183|4. **项目记忆机制**：.cursorrules 让 AI 理解项目上下文
   184|5. **迭代式编辑**：Cmd+K 支持多次迭代，逐步完善代码
   185|6. **多模型支持**：可在 Claude、GPT-4o 之间切换
