    12|# Hello Blog - 我的第一篇博客
    13|
    14|## 前言
    15|
    16|你好！欢迎来到我的博客。这是我的第一篇博客文章，用来记录博客搭建的过程和我的初衷。
    17|
    18|## 为什么写博客？
    19|
    20|写博客有很多好处：
    21|
    22|1. **记录学习过程** - 把学到的知识整理成文字，加深理解
    23|2. **分享经验** - 帮助其他学习者少走弯路
    24|3. **建立个人品牌** - 展示自己的技术能力和学习态度
    25|4. **面试加分** - 博客是最好的项目经历之一
    26|
    27|## 博客技术栈
    28|
    29|这个博客使用以下技术搭建：
    30|
    31|- **VitePress** - Vue 生态的静态站点生成器
    32|- **GitHub Pages** - 免费托管
    33|- **Markdown** - 写作格式
    34|
    35|为什么选择 VitePress？
    36|
    37|1. 我有 Vue 3 开发经验，VitePress 上手零成本
    38|2. VitePress 速度快，构建时间短
    39|3. 支持自定义主题，可以打造独特的博客风格
    40|4. 社区活跃，有很多优秀的插件和主题
    41|
    42|## 博客功能

    48|- ✅ 目录导航
    49|- ✅ 响应式布局
    50|- ✅ 暗色模式

    60|## 搭建过程
    61|
    62|### 1. 初始化项目
    63|
    64|```bash
    65|npm init -y
    66|npm install -D vitepress
    67|```
    68|
    69|### 2. 创建配置文件
    70|
    71|在 `.vitepress/config.ts` 中配置网站基本信息：
    72|
    73|```typescript
    74|import { defineConfig } from 'vitepress'
    75|
    76|export default defineConfig({
    77|  title: '沈同学的博客',
    78|  description: '记录技术学习、项目实战与生活感悟',
    79|  // ... 其他配置
    80|})
    81|```
    82|
    83|### 3. 创建文章
    84|
    85|在 `posts/` 目录下创建 Markdown 文件，VitePress 会自动识别并生成页面。
    86|
    87|### 4. 部署到 GitHub Pages
    88|
    89|```bash
    90|# 构建静态文件
    91|npm run docs:build
    92|
    93|# 推送到 GitHub
    94|git add .
    95|git commit -m "Initial blog"
    96|git push origin main
    97|```
    98|
    99|在 GitHub 仓库设置中启用 GitHub Pages，选择 `gh-pages` 分支作为源。
