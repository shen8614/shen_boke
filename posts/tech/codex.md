    13|    13|# Codex：OpenAI 的沙箱 Coding Agent
    14|    14|
    15|    15|> 官网：[https://openai.com/index/codex](https://openai.com/index/codex) / [https://platform.openai.com](https://platform.openai.com)
    16|    16|
    17|    17|## 简介
    18|    18|
    19|    19|Codex 是 OpenAI 的终端 Coding Agent，基于 codex-1 模型（o3 微调版）。它的核心特色是"沙箱安全执行"——所有命令都在隔离的沙箱中运行，不会影响本地环境。
    20|    20|
    21|    21|Codex 的推理能力非常强，特别适合处理复杂的算法和逻辑问题。`codex exec --full-auto` 模式能自动完成从零到一的项目搭建，沙箱隔离保证不影响本地环境。

    73|    73|## 核心功能
    74|    74|
    75|    75|### 沙箱执行
    76|    76|
    77|    77|Codex 的所有命令都在沙箱中运行，这是它最大的特色：
    78|    78|
    79|    79|- **文件操作**：在隔离目录进行，不影响本地文件系统
    80|    80|- **Shell 命令**：在沙箱容器中执行，无法访问本地环境
    81|    81|- **网络访问**：受限，只能访问必要的依赖源
    82|    82|- **进程隔离**：无法看到或影响本地进程
    83|    83|
    84|    84|这意味着你可以在生产服务器上安全地使用 Codex，不用担心它误操作本地文件。
    85|    85|
    86|    86|### 一次性执行（exec）
    87|    87|
    88|    88|`codex exec` 支持一次性任务执行，完成后自动退出：
    89|    89|
    90|    90|```bash
    91|    91|# 创建项目
    92|    92|codex exec "用 FastAPI 搭一个带 JWT 认证的用户管理系统"
    93|    93|
    94|    94|# 生成代码
    95|    95|codex exec "实现一个 LRU Cache，要求 O(1) 的 get 和 put 操作"
    96|    96|
    97|    97|# 分析代码
    98|    98|codex exec "分析这个项目的依赖关系，找出潜在的安全漏洞"
    99|    99|```
   100|   100|
   101|   101|### 交互式 PTY
   102|   102|
   103|   103|支持交互式终端，可以持续对话：
   104|   104|
   105|   105|```bash
   106|   106|$ codex
   107|   107|╭─────────────────────────────────────╮
   108|   108|│ Codex CLI                           │
   109|   109|│ Type /help for commands             │
   110|   110|╰─────────────────────────────────────╯
   111|   111|
   112|   112|> 帮我分析这个项目的架构
   113|   113|
   114|   114|# Codex 会：
   115|   115|# 1. 扫描项目结构
   116|   116|# 2. 分析依赖关系
   117|   117|# 3. 生成架构图
   118|   118|# 4. 给出优化建议
   119|   119|```
   120|   120|
   121|   121|### full-auto 模式
   122|   122|
   123|   123|全自动模式，不需要任何确认：
   124|   124|
   125|   125|```bash
   126|   126|codex exec --full-auto "重构这个模块，把回调改成 async/await"
   127|   127|```
   128|   128|
   129|   129|Codex 会自动完成所有操作，包括修改文件、运行测试、修复错误。
   130|   130|
   131|   131|### yolo 模式
   132|   132|
   133|   133|跳过所有安全检查，最快执行：
   134|   134|
   135|   135|```bash
   136|   136|codex exec --yolo "快速原型验证"
   137|   137|```
   138|   138|
   139|   139|适合快速验证想法，不建议在正式项目中使用。
   140|   140|
   141|   141|### 并行 worktree
   142|   142|
   143|   143|支持 Git worktree 并行执行多个任务：
   144|   144|
   145|   145|```bash
   146|   146|# 在不同 worktree 中并行执行
   147|   147|codex exec --worktree feature-a "实现功能 A"
   148|   148|codex exec --worktree feature-b "实现功能 B"
   149|   149|codex exec --worktree bugfix-c "修复 Bug C"
   150|   150|```
   151|   151|
   152|   152|每个任务在独立的 worktree 中执行，互不干扰。
